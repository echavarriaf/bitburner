# Bitburner desde Cero

Código de mi serie de YouTube sobre **Bitburner**, donde empezamos una partida completamente nueva y aprendemos a programar y automatizar paso a paso.

La idea de esta serie es construir todo desde cero usando **JavaScript**, **VS Code** y la **Remote API** de Bitburner.

---

## Episodio 1 — VS Code + Primer Script

En este episodio:

- Creamos un proyecto local para Bitburner.
- Instalamos `bitburner-filesync`.
- Configuramos la Remote API.
- Conectamos VS Code con Bitburner.
- Creamos nuestro primer script.
- Ejecutamos `hello.js` desde la terminal del juego.

---

## Requisitos

Necesitas tener instalado:

- Bitburner
- Visual Studio Code
- Node.js
- npm
